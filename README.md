## 📋 Sobre o projeto

O **Lord Perrout Advocacia** é um projeto de website institucional desenvolvido com o objetivo de criar uma presença digital moderna, profissional e confiável para um escritório de advocacia.

A proposta visual busca transmitir **credibilidade, autoridade e sofisticação**, enquanto a estrutura do site prioriza uma navegação intuitiva e uma experiência consistente em diferentes dispositivos.

O projeto foi desenvolvido utilizando tecnologias modernas do ecossistema React/Next.js e disponibilizado em produção através da Vercel.

---

## 🎯 Objetivos

* Criar uma presença digital profissional para o escritório;
* Apresentar a identidade e posicionamento da marca;
* Destacar áreas de atuação e serviços jurídicos;

## 💻 Executando o projeto localmente

### 1. Clone o repositório

```bash
git clone SEU_LINK_DO_REPOSITORIO
```

### 2. Acesse a pasta

```bash
cd lordperrout-advocacia
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

### 5. Acesse no navegador

```text
http://localhost:3000
```
